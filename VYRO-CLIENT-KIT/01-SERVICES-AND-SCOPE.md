# VYRO Studio — Services & Scope Guide

**Positioning:** Independent creative studio — Ideas into Impact.

## Services

### Brand identity
Possible scope: discovery, positioning direction, logo concept, supporting marks, color/type system, basic usage sheet, selected mockups.

### Website / digital design
Possible scope: sitemap, visual direction, responsive page design, static front-end implementation, basic metadata and QA. Backend, authentication, database, checkout and ongoing hosting are separate scopes and are not currently included.

### Graphic design / campaigns
Possible scope: campaign concept, social post system, digital posters, banners, simple launch asset set and export-ready files.

### Illustration / character design
Possible scope: original character direction, expression/pose sheet, profile illustration and agreed digital applications.

### 3D / visual artwork
Possible scope: still render concepts, abstract visual compositions and agreed export formats. Complex animation, simulations and product-accurate visualization require separate assessment.

## Quote every project individually
Do not publish a fixed price until the studio has reviewed the brief, deliverables, timeline, revision rounds, usage rights and complexity. Every quote should state:
- Exact deliverables and file formats
- What is excluded
- Number of revision rounds
- Milestones and estimated timeline
- Total fee and currency
- Payment schedule, only after an adult-supervised payment method is approved
- Ownership / license terms in writing

**Internal launch note:** Rates are intentionally not filled in here. Validate pricing with a parent/guardian and compare the actual time and complexity of each job before sending a quote.
