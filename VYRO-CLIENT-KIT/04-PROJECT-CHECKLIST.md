# VYRO Studio — Project Delivery Checklist

## Before accepting
- [ ] Client and decision-maker identified
- [ ] Brief, audience and goal understood
- [ ] Deliverables and file formats listed
- [ ] Timeline checked against school/personal commitments
- [ ] Price and revision rounds agreed
- [ ] Usage / ownership terms reviewed
- [ ] Parent/guardian reviews client agreement and payment setup

## During production
- [ ] Save dated working versions
- [ ] Use licensed or original assets
- [ ] Share progress only at agreed milestones
- [ ] Record feedback in one written channel
- [ ] Confirm any scope changes and extra costs before doing them

## Before delivery
- [ ] Check spelling, dimensions, exports and links
- [ ] Confirm all agreed deliverables are present
- [ ] Confirm final approval and agreed payment milestone
- [ ] Deliver files through an agreed method
- [ ] Archive project files securely
- [ ] Ask permission before publishing client work as a case study
